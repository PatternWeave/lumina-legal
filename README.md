# Lumina Hue — privacy and support

Public App Store pages for **Lumina Hue** (Philips Hue lighting companion).

- **Privacy policy (HTML):** [index.html](index.html) (this is the page reviewers and customers should open)
- **Privacy policy (markdown):** [PRIVACY.md](PRIVACY.md)
- **Support email:** [support@lumina.app](mailto:support@lumina.app)

Lumina does not create an account. Named lighting commands run on your iPhone and go to your Hue Bridge or the official Hue Remote API. Optional Microsoft Phi-3 Mini is downloaded once, with consent, and stays on device.

The iOS app source is private. This repository exists so App Store Connect can link a public Privacy Policy URL and Support URL.
